# IsoAtlas

在浏览器里生成专业地形图风格的等高线地图，支持多山峰、盆地、自然噪声与 PNG / JPG / SVG 导出。

在线使用：https://euclase2333.github.io/IsoAtlas/

---

## 这是什么

IsoAtlas 是一个纯前端的等高线地图生成工具，打开网页就能用，不需要安装任何软件。

输入几个参数，就能生成一张专业地形图风格的等高线图：

- 等高线是真正的线条，不是字符拼的
- 每一圈线上标注 1~2 个高度数字，数字跟随线条弧度
- 支持山、盆地、多个中心点、山体自动融合
- 地形带自然噪声，等高线疏密自然，不是同心圆
- 可以导出 PNG / JPG / SVG

---

## 功能

### 地形
- 山 / 盆地
- 多个中心点，可添加、删除、拖动、改高度
- 山体靠近时自动融合
- 起始半径（中心附近留白，不画等高线）

### 等高线
- 层数可调
- 起始 / 结束范围可调
- 线宽可调
- 计曲线（每隔几条加粗）可开关
- 噪声细节可调，控制线条自然弯曲程度

### 标注
- 高度数字可显示 / 隐藏
- 字号可调（6~200px）
- 数字颜色可单独设置
- 数字描边可开关
- 字体可选（自动检测本机字体，也支持手动输入字体名）

### 山顶标记
- 可整体隐藏
- 红点颜色、文字颜色、文字字号可调

### 颜色
- 背景、普通等高线、计曲线、数字、山顶标记，均可单独设色
- 6 套预设配色：默认白 / 默认黑 / 地形图 / 牛皮纸 / 天空蓝 / 深海蓝

### 导出
- 格式：PNG / JPG / SVG
- 可选择是否包含背景（PNG / SVG 支持透明背景）
- SVG 文字自动转路径，任何电脑打开都不会变字体
- 分辨率：宽高最大 10000 × 10000 px，DPI 72~300
- 实时显示对应的打印尺寸

## 怎么用

1. 打开网页
2. 在右侧面板调参数，左侧实时预览
3. 调好后点「导出」，选格式和分辨率，浏览器自动下载

提示：
- 参数面板可以折叠，点标题行即可展开 / 收起
- 画布区和参数区各自独立滚动，互不干扰
- 导出大图（8000px 以上）可能要等几秒到几十秒，属正常

## 常见问题

**页面空白 / 报错**
按 F12 打开开发者工具，看 Console 里的红色报错。

**改了参数但预览没变**
检查是不是勾了「计曲线使用相同颜色」之类的联动选项，取消勾选后单独设置的输入框才会出现。

**导出大图卡住**
8000px 以上导出计算量大，通常几秒到几十秒会完成。如果超过 1~2 分钟没反应，先把「噪声细节」和「层数」调低再试。

**刷新后看不到最新效果**
浏览器缓存了旧文件，用 Ctrl+Shift+R（Mac 是 Cmd+Shift+R）强制刷新。

**导出透明 PNG 后，某些软件打开是黑底**
那只是显示问题，文件本身是透明的。用 Photoshop、GIMP 或拖进浏览器里看，就能看到透明棋盘格。

**导出 JPG 时透明区域变黑**
JPG 格式不支持透明，透明区域会被填成白色。这是正常的。

**SVG 里的数字变成了默认字体**
IsoAtlas 的 SVG 导出会把文字自动转成路径，正常情况下不会出现这个问题。如果出现了，说明导出时字体转换失败，请反馈。

## 技术说明

- 纯前端，单个 `index.html`，无后端、无数据库
- 地形：高斯函数 + 值噪声（Value Noise）叠加
- 等高线：Marching Squares 算法追踪
- 数字标注：沿等高线路径找平缓处，按文字宽度开缺口
- SVG 文字：离屏 Canvas 渲染 + 透明度边界追踪 + `fill-rule="evenodd"` 拼成 `<path>`

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库
2. 把 `index.html` 上传到仓库根目录
3. 打开仓库的 Settings → Pages
4. Source 选 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)`，保存
5. 等 1 分钟左右，访问 `https://你的用户名.github.io/仓库名/`

以后要改：打开仓库里的 `index.html`，点铅笔图标编辑，全选替换，Commit，强制刷新页面。
